# ADR-0009 — Studio stack (shadcn + Tailwind v4 + Refine headless)

Status: Accepted · Date: 2026-09-17

## Decision

No Material UI. Refine headless for data/auth wiring; shadcn new-york + Tailwind v4 for presentation; Orval from OpenAPI.

## Consequences

Figma is visual SoT; one generated HTTP client; tokens via CSS variables.
