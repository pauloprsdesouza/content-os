# Glossary

| Term | Meaning |
|---|---|
| Aggregate | Consistency boundary protecting invariants |
| Application port | Narrow interface owned inward, implemented in Infrastructure |
| Claim | Reviewable statement supported by Evidence |
| Evidence | Addressable observation on an immutable Snapshot |
| Operation | Durable async work resource (`202` + status URL) |
| PublicationPackage | Deterministic manifest + asset hashes for distribution |
| Snapshot | Immutable capture of a Source (SHA-256 blob) |
| Outbox/inbox | Couples state change and reliable messaging |
| Idempotency | Repeat handling = same business effect |
| Provenance | Lineage Source → … → Publication / Outcome |
